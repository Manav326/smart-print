STRAIGHT ANSWERS ABOUT SMARTPRINT

SmartPrint questions, clearly answered

SmartPrint by QuantaEdge is print-shop workflow software. It connects a participating shop's QR-code document intake, job review, shop-controlled approval and Windows printer workflow. These answers explain what the product does—and where its boundaries are.

Explore print-shop softwareSee how it works

What is SmartPrint?

SmartPrint is software that helps local print shops receive supported document-print requests from customers, review those requests, prepare quotes, confirm payment, approve jobs and dispatch authorised work to connected shop printers. Customers can start by scanning the participating shop's QR code.

How SmartPrint works

Who is SmartPrint designed for?

SmartPrint is designed for independent print shops that want a connected way to manage customer document submissions and shop-side print fulfilment. It also provides a simpler document handoff for customers of participating shops.

How does QR code print ordering work?

A customer scans the QR code displayed by a participating print shop. The code opens that shop's SmartPrint submission page. The customer selects a supported document and submits the request. The shop then reviews the document and print details, prepares a quote and controls whether the job is approved.

Does SmartPrint print a document automatically after upload?

No. Uploading a document does not start printing. The shop reviews the request, confirms the quote and payment according to its process, explicitly approves the job and dispatches authorised work to a printer.

Which document formats does SmartPrint support?

The current customer print workflow supports PDF, JPG, JPEG and PNG files. The documented hard limit is 20 MB per job file, and PDF documents can contain up to 500 pages.

Does SmartPrint replace a shop's existing printer or printer driver?

No. The SmartPrint Windows Agent connects the shop workspace to printer queues already installed on the shop's Windows computer. Printer compatibility still depends on the printer, its Windows driver and the shop's configuration.

Can a shop receive documents over its local Wi-Fi network?

SmartPrint supports a local shop-network transfer route for supported workflows. In that route, document bytes can remain on the shop network. The SmartPrint service is still required for QR-session validation, upload authorisation, job metadata, quotes and dispatch approval.

Does local document transfer mean SmartPrint works fully offline?

No. Local transfer does not make the complete product an offline printing system. SmartPrint still uses its service to coordinate the customer session, print job, quote and approval lifecycle.

Can the shop choose which printer receives an approved job?

Yes. The shop workspace supports printer assignment for authorised work through the connected Windows Agent. The shop remains in control of approval and dispatch.

Does SmartPrint collect the customer's print payment automatically?

The shop controls its own print pricing and payment process and confirms payment before dispatch. SmartPrint's shop subscription payment is a separate financial flow from the customer's payment for printing at the shop.

Is SmartPrint a printing company or a directory of nearby print shops?

No. SmartPrint is workflow software used by participating print shops. Each shop provides its own printing service, manages its own customers and controls fulfilment. SmartPrint does not claim to be a public directory or a document-printing fulfilment company.

Can customers use SmartPrint from a phone?

Customers can open the shop-specific submission flow in a mobile browser after scanning the shop QR code. SmartPrint also has a native Android companion app for the supported customer document workflow.

Where can a print shop learn about the Windows Agent?

The Windows Agent connects a shop's Windows computer and installed printer queues to its SmartPrint workspace. Read the Windows Print Agent guide for its role, setup and workflow boundaries.

How long are customer documents kept?

Standard Printing: Under the default standard policy, any completed source copy stored by SmartPrint or on the paired shop computer is retained for 7 days after confirmed physical output or verified PDF export. It is then purged on the next hourly cleanup sweep. Jobs whose output is not confirmed remain available for recovery and reconciliation.

Private Printing: The document is sent end-to-end encrypted to the paired shop computer and is not placed in the normal cloud document store. The shop computer securely erases its working copy as soon as physical output is confirmed. If a temporary encrypted relay was needed for transfer, that relay copy is removed after the Agent has verified receipt.

These rules apply to SmartPrint's working copies. SmartPrint does not delete the original file from the customer's phone or document library. Job, payment and audit metadata are retained separately so the shop can reconcile completed work.

SmartPrint at a glance

  • Product: Print-shop workflow software by QuantaEdge
  • Primary users: Participating local print shops and their customers
  • Customer entry: Shop-specific QR code and mobile submission page
  • Supported print files: PDF, JPG, JPEG and PNG
  • Document limits: 20 MB per file; PDF up to 500 pages
  • Shop-side printer connection: SmartPrint Windows Agent and installed Windows printer queues
  • Approval: Explicitly controlled by the print shop
  • Transfer options: Supported local shop-network or cloud-assisted routes
  • Offline status: The full job workflow requires SmartPrint service connectivity
