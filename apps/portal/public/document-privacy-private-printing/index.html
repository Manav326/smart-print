CUSTOMER CHOICE · SHOP CONTROL

Document privacy is part of the print workflow

Print shops handle personal, academic, business and identity documents. SmartPrint gives customers a choice between Standard Printing and Private Printing, while keeping the shop's quote, payment, approval and physical-output responsibilities clear.

Explore all SmartPrint featuresHow the Windows Agent works

Choose how the shop-side working copy is handled

The customer selects the document mode before uploading a batch. Private Printing is available only when the paired shop computer is connected and has provided its secure document-encryption key. The selected mode applies to the whole batch.

Standard Printing

Use the shop's normal print workflow. Completed source copies are retained for 7 days by default after confirmed physical output or verified PDF export, then removed by the configured cleanup process.

Private Printing

Use a privacy-focused mode for supported physical print jobs. The document is encrypted before it leaves the customer's device and sent to the paired shop computer. The source is not placed in the normal cloud document store, and managed PDF export is disabled.

What happens in Private Printing

1. The customer chooses Private Printing

The option appears only when the shop's paired Windows computer is connected and has enabled its secure document key. If the shop is not ready, SmartPrint tells the customer that no document has been uploaded.

2. The document is encrypted on the customer's device

SmartPrint encrypts the source before transfer and prepares it for the paired Agent. The paired shop computer is the intended document recipient.

3. The paired Agent receives and validates it

The Agent decrypts the content in memory, checks the source hash and document structure, and stores its protected local working copy in the DPAPI-protected queue. If direct shop Wi-Fi is not ready, the transfer can use a temporary encrypted relay.

4. The shop still controls the order

The shop manages the quote, payment status, approval/rejection, printer assignment and dispatch. The private source itself is not available for shop preview/download or shop-side photo revision.

5. The Agent removes its working copy after confirmed output

Once the shop confirms actual physical output, the paired Agent securely overwrites and deletes its private working copy, then acknowledges the purge. The service redacts source metadata after that acknowledgement.

What remains after a Private Printing job

  • The document source: it is not placed in the normal cloud document store; the paired Agent working copy is removed after confirmed physical output and deletion acknowledgement.
  • The temporary relay: when used, the encrypted relay object is removed after the Agent verifies receipt.
  • The customer's original: the original document in the customer's own phone or document library is unchanged and is not deleted by SmartPrint.
  • Job and payment history: job, payment and audit metadata remain so the shop can reconcile the order, collection and refund history.
  • Physical output: Private Printing is for physical printing only. Managed PDF export is disabled for the private source.

Private Printing is a document-retention choice, not an anonymous order or anonymous payment mode. The shop still sees and manages the job and its commercial status. If output is uncertain, the protected source is retained for reconciliation rather than deleted too early.

Standard Printing: default retention

Standard Printing uses the shop's normal document workflow. Under the default policy, completed source copies stored by SmartPrint or on the paired shop computer are retained for 7 days after confirmed physical output or verified PDF export, then removed by the configured cleanup process.

Unfinished jobs, output-unconfirmed work and items under financial hold are not prematurely removed. Job, payment and audit metadata are kept separately so the shop can reconcile the transaction and fulfilment history. Retention settings may be centrally configured by the platform operator.

Shop Wi-Fi and Cloud-assisted transfer are different

Standard Shop Wi-Fi transfer

For supported standard jobs, the phone sends document bytes directly to the paired Windows Agent over the selected shop network. This path uses local HTTP and is not encrypted in transit. It is restricted to the selected local subnet, trusted portal origin and a one-use upload grant. Do not treat this mode as end-to-end encrypted or use it on guest/public Wi-Fi.

Cloud-assisted transfer

Where the shop's plan enables it, documents are uploaded through the HTTPS portal/API and retrieved by the paired Agent over authenticated HTTPS. Cloud document storage is encrypted at rest.

Private Printing is different from the standard local route: its source is encrypted before leaving the customer's device and can use a temporary encrypted relay when direct Shop Wi-Fi is unavailable. Neither transfer option makes SmartPrint a fully offline system; QR sessions, job details, quotes, payment status and dispatch still rely on the SmartPrint service.

Document privacy: common questions

Does Private Printing hide the order from the shop?

No. The shop still sees the job and its quote, payment and output state. The private source document is not available for shop preview/download.

Does SmartPrint delete the original file from my phone?

No. SmartPrint only manages the working copies used by the print workflow. The original file in the customer's own phone or document library is unchanged.

Is Private Printing available at every print shop?

No. The paired shop computer must be connected and have enabled its secure document key. SmartPrint does not upload the document when that setup is unavailable.

Is ordinary Shop Wi-Fi upload encrypted in transit?

No. Standard direct Shop Wi-Fi transfer uses local HTTP and is not encrypted in transit. The encrypted Private Printing mode is separate. Cloud-assisted transfer uses HTTPS when included in the shop's plan.

Can a Private Printing job be saved as a PDF by the shop?

No. Private Printing is restricted to physical printer output; managed PDF export is disabled for its private source.

Does Private Printing make an order anonymous?

No. Job, payment and audit metadata remain available for shop operations and reconciliation. Private Printing controls handling of the source document copy.
